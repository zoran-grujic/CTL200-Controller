NOTES ON UNDOCUMENTED COMMANDS:
- model/modelno/modelnumber: Returns full device model designation. Format: BASE-REVISION-MAXCURRENT (e.g., CTL200-0-B-200 means CTL200-0 base model, revision B, 200mA max current)
- calibration: Factory-set ADC/DAC calibration values. These are critical for measurement accuracy. DO NOT attempt to write or modify these values!
- config/configuration: Quick way to read all TEC controller settings in a single command instead of querying each parameter individually. Very useful for logging or backup purposes.
- All undocumented commands follow the same protocol: send command with \r terminator, device echoes command, then responds with data, then sends >> prompt
- These commands were discovered through systematic testing on device S/N 17095 running firmware V0.17
